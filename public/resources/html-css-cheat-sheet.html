HTML & CSS Cheat Sheet

CHRISCO Digital Academy — Your quick reference to the building blocks of every website.

HTML Essentials

  • <h1> to <h6> — Headings. Use one <h1> per page.
  • <p> — Paragraph of text.
  • <a href="url"> — Link. Add target="_blank" to open in a new tab.
  • <img src="" alt=""> — Image. Always fill in alt.
  • <ul>/<ol> + <li> — Unordered and ordered lists.
  • <div> — Block container. <span> — Inline container.
  • <button> — Clickable action. <input> — Form field.

CSS Selectors

/* element */        p { color: #0a0a0a; }
/* class */          .card { border: 3px solid #000; }
/* id */             #hero { padding: 40px; }
/* hover */          .btn:hover { transform: translate(-2px,-2px); }
/* descendant */     .card h2 { font-size: 1.5rem; }

The Box Model

Every element is a box made of four layers: content, padding (inside), border, margin (outside). Use box-sizing: border-box; so padding and border are counted inside the width.

Flexbox in 30 Seconds

.container {
  display: flex;
  justify-content: space-between; /* main axis */
  align-items: center;            /* cross axis */
  gap: 16px;                      /* spacing */
  flex-wrap: wrap;                /* wrap on small screens */
}

Grid in 30 Seconds

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

Typography

  • font-size, font-weight, line-height
  • font-family: 'Inter', sans-serif;
  • text-align: center; / left / right
  • letter-spacing, text-transform: uppercase
