Variables and Types

name = "Aisha"        # str (string, text)
age = 19              # int (whole number)
height = 1.65         # float (decimal)
is_learning = True    # bool (True or False)
scores = [80, 90, 75] # list
person = {"name": "Aisha", "age": 19}  # dict

Print and Input

print("Hello, CHRISCO")

Math

x = 10 + 5     # add
x = 10 - 5     # subtract
x = 10 * 5     # multiply
x = 10 / 5     # divide (gives float)
x = 10 // 3    # floor divide
x = 10 % 3     # remainder (modulo)
x = 2 ** 3     # exponent (2 to power 3 = 8)

If / Elif / Else

score = 75
if score >= 80:
    print("Grade A")
elif score >= 60:
    print("Grade B")
else:
    print("Keep going")
Indentation matters in Python. Use 4 spaces. Never mix tabs and spaces.

Loops

# for loop over a list
for name in ["Aisha", "Brian", "Neema"]:
    print("Hello " + name)

# for loop with range
for i in range(5):    # 0, 1, 2, 3, 4
    print(i)

# while loop
count = 0
while count < 5:
    print(count)
    count = count + 1

Functions

def greet(name):
    return "Hello " + name

print(greet("Benjamin"))

def add(a, b):
    return a + b

print(add(3, 7))   # 10

Lists

fruits = ["mango", "banana", "orange"]
fruits.append("pawpaw")      # add to end
fruits[0]                    # first item
len(fruits)                  # length
for f in fruits:
    print(f)

Dictionaries

student = {

Working with Files

# Read a file
with open("notes.txt", "r") as f:
    content = f.read()
    print(content)

# Write a file
with open("output.txt", "w") as f:
    f.write("Done for today.")

Try / Except (errors)

try:
    num = int(input("Enter a number: "))
    print("Great:", num)
except ValueError:
    print("That was not a number.")

Useful Built In Functions

  • len(x) — length of string, list, etc.
  • max(list), min(list), sum(list)
  • sorted(list) — return sorted version
  • range(n) — numbers 0 to n minus 1
  • type(x) — check the type
  • int("5"), str(5), float("3.14") — convert
