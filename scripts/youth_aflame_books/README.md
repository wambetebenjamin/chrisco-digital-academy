# CHRISCO Youth Aflame study books

Build both print-ready A4 PDFs from the repository root:

```sh
python -m pip install -r scripts/youth_aflame_books/requirements.txt
python scripts/build_youth_aflame_books.py
```

The output PDFs are written into `content/books/`.

- `stop-making-our-god-look-like-baal.pdf` — a 24-page study of 1 Kings 18, biblical prayer, discernment, and pastoral safeguards.
- `young-pastor-10-truths-about-your-calling.pdf` — a 30-page formation guide with teaching and reflection for each of ten ministry truths.

The visual direction follows the A4 portrait page size, navy capsule headings, cream geometry, small starburst accents, photo bands, and footer rhythm of `BOOK FOR TODAY.pdf`; text and vector illustrations are newly written for CHRISCO Youth Aflame. Scripture references and short KJV quotations are used throughout. Image details and attribution are in `IMAGE-CREDITS.md`.
