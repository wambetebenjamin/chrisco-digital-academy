## Typefaces
- Inter Regular is distributed under the SIL Open Font License; the license is included as `assets/fonts/Inter-LICENSE.txt`. It is used for body copy to match the reference.
- Poppins Bold is an existing project font used for new display headings. The reference PDF embeds only a limited subset of its Code Pro display face; a complete Code Pro font file was not available in the project. The builder therefore uses the project’s full-glyph Poppins Bold rather than redistributing a commercial font without its license.

## Artwork and layout
The underlying 10-page layout, geometric shapes, color fields, capsules, dividers, ornaments, and photo frames are retained from the user-provided `BOOK FOR TODAY.pdf`. The sample copy and its unrelated stock photographs are replaced. The small CHRISCO ring mark is redrawn in vector form.
